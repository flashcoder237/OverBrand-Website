On Cherche

  • Curiosité Obsessionnelle

    Vous cherchez à comprendre comment les choses fonctionnent sous le capot, pas juste à utiliser le framework du moment.

  • Sens du détail extrême

    Le pixel parfait, l'animation fluide, le code sec. L'art se cache dans les petites finitions.

  • Écriture Claire

    Que ce soit pour une PR de 50 lignes ou un message Slack, vous structurez votre pensée avec limpidité.

  • Autonomie Asynchrone

    Vous n'avez pas besoin d'être micro-managé. Vous identifiez les bloqueurs et avancez.

On ne cherche pas

  • Les "Experts en tout"

    L'humilité est reine. Personne ne maîtrise tout. Avouez quand vous ne savez pas, puis apprenez.

  • Attardés du CV (10+ ans obligatoires)

    Nous valorisons la vélocité et l'impact de vos projets récents plus que la durée sur une chaise.

  • Ceux qui attendent les instructions

    Si vous voyez un problème d'UX, proposez une solution. Ne codez pas aveuglément des specs cassées.

  • Corporate Talk

    Ici, pas de "synergie", de "gérer les stakeholders", ou de politique. On construit des choses.
