Mandat .

Nexus Finance voulait unifier 3 produits SaaS fintech sous une même interface, pour 50k+ utilisateurs professionnels. Le design system existant était fragmenté, chaque équipe avait reconstruit ses propres composants en vase clos.

Challenge : Créer un design system robuste, visuellement radical mais hyper-fonctionnel, utilisable par 4 squads produit sans freiner leur vélocité d'expédition.

Chapitre_02 / La Typographie

Hiérarchie
Radicale.

L'interface nécessitant une lecture dense de données financières, nous avons banni les typographies décoratives. Le choix s'est porté sur une famille sans-serif géométrique pseudo-grotesque pour l'UI, garantissant une lisibilité parfaite sur les petits écrans.

Pour les données tubulaires et les tickers financiers, JetBrains Mono a été intégré, permettant un alignement vertical mathématique crucial pour les traders.

Behind the scenes

Bilan de l'Opération

1.

Cohérence Absolue

Les 3 produits phares de Nexus (Banking, Trading, Analytics) respirent enfin la même identité visuelle. L'apprentissage utilisateur d'un module à l'autre est devenu quasi nul, réduisant le taux de rebond inter-applications de 34%.

2.

Écovolontarisme Tech

En centralisant les composants frontend, la dette technique a été massivement purgée. Le poids global du bundle CSS/JS envoyé au client a été divisé par trois, améliorant les performances du dashboard de 1.2s sur le First Contentful Paint.
